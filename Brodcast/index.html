Domaines OBS-szinkron beállítása

A kezelőoldal és az OBS külön böngészőt használ, ezért a változásokhoz Firebase Realtime Database szükséges. Töltsd ki a firebase-config.js fájlt a Firebase webalkalmazás adataival, engedélyezd az Anonymous bejelentkezést, majd telepítsd a projektben lévő database.rules.json szabályokat. A Firebase Console-ban a domainedet is add hozzá az engedélyezett domainekhez.

Első csatlakozás beállítása

A Rocket League telepítési mappájában nyisd meg a TAGame/Config/TAStatsAPI.ini fájlt (ha ez nincs, a DefaultStatsAPI.ini-t), és a [TAGame.MatchStatsExporter_TA] szakaszban állítsd be az alábbi értékeket. Ezután indítsd újra a játékot.

PacketSendRate=60
Port=0
WebPort=49124

Az API a helyben futó Rocket League aktuális meccsét küldi. Privát meccs közvetítéséhez a Rocket League fusson azon a gépen, amelyik az adatokat küldi, és azon a gépen játssz vagy spectatorként figyeld a meccset. Az OBS böngészőforrás is erre a gépre csatlakozzon. A hivatalos leírás nem sorolja fel külön a játékmódokat. Hivatalos API útmutató ↗
